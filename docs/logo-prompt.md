# LinguaBridge logo prompt

Create a 128x128 transparent PNG icon for a Minecraft Fabric mod named **LinguaBridge**.

Style: clean modern Minecraft-inspired pixel art, crisp edges, readable at 16x16, no text-heavy logo, transparent background.

Composition: two overlapping Minecraft-style chat bubbles, one slightly higher left and one lower right. Add a simple translation symbol between them: two opposing curved arrows or a compact A/文-inspired translation glyph. The bubbles should feel like communication between two languages. Use a restrained palette inspired by Minecraft UI: deep charcoal, off-white, cyan/teal accent and a small warm gold accent. Strong silhouette, centered composition, no border outside the bubbles, no shadows that require a background.

The icon must remain recognizable when reduced to 32x32 and 16x16. Avoid gradients, photorealism, 3D rendering, thin details, characters, flags and long text.

Output exactly 128x128 pixels with transparent alpha background.
